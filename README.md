# MNS Themes

Custom themes for MidnightScene. More on the way.

## Install

1. On MNS, go to **Settings → General** and set **Theme** to **MidnightScene**.
2. Paste a theme link from below into **External CSS stylesheet**. Leave **Standalone** empty.
3. Save, then hard-refresh: **Cmd + Shift + R** (Mac) or **Ctrl + Shift + R** (Windows).

To go back to the default look, clear the box and save. Updates apply automatically.
