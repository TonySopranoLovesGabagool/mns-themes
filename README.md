# MNS Themes

Custom themes for [MidnightScene](https://midnightscene.cc). Each theme is a single CSS file you load from your MNS settings. No extensions or installs needed.

More themes are on the way. This repo will keep growing as new ones are added, and existing links won't change when that happens.

---

## Nightshift

An OLED-black theme with a night sky wallpaper and gold accents.

- **True black panels** over a dark wallpaper of blue clouds and a scattered starfield
- **Gold highlights** only where it matters: the page you're on, the current tab, hovered rows, focused inputs and the active page number
- **Glass header** that lets the sky show through behind the logo and stats
- **Moon and clouds logo** in the header
- **Separate mobile wallpaper**, cropped for portrait screens
- **Cleaner forms**, with readable labels and visible outlines on inputs and dropdowns
- User group colors and the seeder/leecher/freeleech colors are left as they are

### Install

1. On MNS, go to **Settings → General**.
2. Set **Theme** to **MidnightScene**. Nightshift is built on top of it.
3. Paste this link into **External CSS stylesheet (stacks on top of above theme)**:

   ```
   https://tonysopranolovesgabagool.github.io/mns-themes/nightshift.css
   ```

4. Leave **Standalone CSS stylesheet** empty.
5. Save, then hard-refresh with **Cmd + Shift + R** (Mac) or **Ctrl + Shift + R** (Windows).

To go back to the default look, clear the External CSS box and save.

### Notes

- Updates show up automatically. You never need to change the link.
- If the theme doesn't show up after saving, wait a few minutes and hard-refresh again. The file can take a moment to update after changes.
- Found something that looks off? Send me a screenshot and the page it's on.

## Moon Landing

A liquid glass theme set on the surface of the moon, in the grey and black of Apollo mission photos, with neon cyan accents.

- **Moon surface background**: sharp craters at the edges of the screen, fading to black behind the content
- **Liquid glass panels** with blur, a light top edge and a soft shadow, so they float over the surface
- **Tables that blend into the glass** instead of solid rows
- **Cyan glow on hover** for rows, menus, dropdown items, links, icons, buttons and inputs
- **Silver moon logo** with a soft glow
- User group colors and the seeder/leecher/freeleech colors are left as they are

Install the same way as Nightshift, using this link:

```
https://tonysopranolovesgabagool.github.io/mns-themes/moonlanding.css
```
